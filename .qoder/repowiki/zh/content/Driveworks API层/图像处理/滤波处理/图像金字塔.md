- 金字塔构建
  - 从首级（最高分辨率）图像开始，逐级下采样生成各级图像
  - 支持指定CUDA流与上下文

### 数学原理与递归关系（概念性说明）
- 尺度空间理论
  - 通过平滑核对图像进行连续尺度变换，形成尺度空间
  - 高斯核作为平滑算子，控制尺度参数
- 多分辨率表示
  - 金字塔将图像在不同尺度下表示，便于多尺度分析
- 高斯金字塔
  - 对相邻层级进行高斯平滑与降采样
  - 递归关系：L_{k+1} = G_σ * L_k（下采样）
- 拉普拉斯金字塔
  - 由高斯金字塔的差分构成：L_k = D_k(G_k)
  - 可用于图像重建与融合
- 下采样与上采样
  - 下采样：隔点采样或卷积后降采样
  - 上采样：零插入与插值核重建

## 性能考虑
- 多尺度并行化
  - 金字塔各级可并行处理，充分利用GPU/PVA并行能力
- 内存带宽
  - 控制金字塔层级数与像素类型，平衡精度与内存占用
- 流水线
  - 将准备、构建、后处理拆分为不同阶段，减少等待时间
- 采样策略
  - 合理选择下采样与上采样策略，降低计算开销

## 故障排查指南
- 常见错误与原因
  - 输入图像尺寸与创建时不一致
  - 不支持的像素类型
  - 内存布局不符合要求
  - CUDA流或PVA配置错误
- 排查步骤
  - 核对创建参数与输入图像属性
  - 检查平台是否支持PVA路径
